# Bloom — Kindergarten WordPress Block Theme

A joyful, sunny block theme for kindergartens, preschools, and kids gardens. Built for Full Site Editing with a complete `theme.json` design system, playful rounded typography, sticker-style badges, and ready-made patterns for programs, teachers, galleries, events, and enrollment.

## Features

- Full Site Editing (block theme) — edit everything visually, no code needed
- Complete design system in `theme.json`: sunny palette, Baloo 2 + Quicksand type, fluid sizes, soft shadows
- 8 templates: front page, blog, single post, page, wide page, no-title page, archive, search, playful 404
- 10 hand-built block patterns: hero, programs grid, features, animated stats, gallery, teachers, testimonials, enrollment CTA, events list, parent FAQ
- "Sunset" style variation — one-click warm alternative look
- Bouncy hover states, floating stickers, marquee, scroll reveals, animated counters (all respect `prefers-reduced-motion`)
- Accessibility-minded: skip link, focus-visible rings, semantic landmarks, alt text
- Translation-ready (`bloom` text domain), GPL-2.0-or-later

## Installation

1. Download or clone this repository.
2. Copy the `bloom-kindergarten-theme` folder into `wp-content/themes/`.
3. In WordPress admin, go to **Appearance → Themes** and activate **Bloom**.
4. Customize everything under **Appearance → Editor** (Site Editor): header, footer, templates, colors, fonts.
5. Try the **Sunset** style variation under Styles in the Site Editor.

Requires WordPress 6.4+ and PHP 7.4+.

## Customization

- **Colors & fonts:** Site Editor → Styles — every color, gradient, and type size lives in `theme.json`.
- **Patterns:** edit any pattern's copy or swap photos right in the editor.
- **Custom block styles:** Sunny / Sky / Grass buttons, Sticker images, Soft card groups, Big quotes.
- **Demo photos:** pattern images load from Unsplash (internet required); replace them with your own photos anytime.
